# SuperStore Retail Core Pipeline

A data analysis project on Superstore sales data focusing on transactional trends, top products, and overall business profit analysis.

## Key Features
* Cleansed raw store transactional records and parsed datetime attributes.
* Discovered monthly sales velocities and customer volume spikes.
* Isolated the top revenue-driving products and created high-impact executive dashboards.

## Tools & Libraries Used
- **Language:** Python
- **Data Manipulation:** Pandas & NumPy
- **Data Visualization:** Matplotlib & Seaborn
- **Environment:** Jupyter Notebook
